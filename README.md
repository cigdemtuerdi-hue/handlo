# Medgift LLC — Website

Simple public website for **Medgift LLC**, with Google Analytics (`G-Y4XFC49M0G`) included.

## Publish for free (GitHub Pages)

1. Merge this branch / use these files on `main`.
2. Open the repo on GitHub: **Settings → Pages**.
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Click **Save**.
5. Wait 1–2 minutes, then open:

`https://cigdemtuerdi-hue.github.io/desktop-tutorial/`

6. Check Analytics: [Google Analytics → Realtime](https://analytics.google.com)

## Edit later

- Page text: `index.html`
- Design: `styles.css`
- Contact email: change the `mailto:` link in `index.html`
